# 会津大学「ミニDX化支援業務」依頼内容

## 社内規程AI確認システムの開発

- 日付: 2026年9月3日
- 依頼元: 株式会社 大和田測量設計

---

## 1. 開発の目的

本システムは、会社の規定類、マニュアル、手続書類をAIに参照させ、社員が自然な言葉で質問できるシステムを構築することを目的とする。

## 2. 現在の課題

当社には、就業規則、旅費規程、通勤手当規程、住宅手当規程、退職金規程、表彰規程、安全衛生管理規程など、複数の社内規程が存在している。

しかし、社員が必要なときに該当する規程を探し、正しく理解するには時間がかかっている。また、総務担当者や管理者に同じような質問が繰り返され、確認作業の負担が発生している。

一方で、一般的な生成AIをそのまま使うと、インターネット上の一般論や会社外の情報を根拠に回答してしまい、当社の正式な規程と異なる説明になる危険がある。

そのため、会社が登録した規程類のみを根拠として回答し、根拠がない場合は推測せず「規程上は確認できません」「未整備の可能性があります」と答える仕組みが必要である。

## 3. 実現したい内容

社員が自然な言葉で質問すると、AIが会社規程の中から該当箇所を探し、根拠となる規程名・条文を示しながら、わかりやすく回答する仕組みを試作したい。

- 質問例：出張の日当はいくらですか。
- 質問例：通勤手当はどのような場合に支給されますか。
- 質問例：住宅手当の対象者は誰ですか。
- 質問例：退職金はどのように計算されますか。
- 質問例：在宅勤務のルールはありますか。

該当する規程がある場合は、回答文とともに規程名・条番号・該当条文を表示する。該当する規程がない場合は、AIが一般論で補完せず、未整備事項として判定する。

## 4. 重要な設計条件

本件で最も重要な点は、AIに自由に答えさせることではなく、AIが根拠のない回答をしない仕組みを作ることである。

- 会社規程以外の一般情報を使わない。
- インターネット検索を行わない。
- 会社が登録した規程類のみを回答根拠とする。
- 回答には、根拠となる規程名・条文を表示する。
- 根拠条文が見つからない場合は、推測せず「確認できない」「未整備の可能性がある」と回答する。
- 未整備と判定された質問を蓄積し、今後の規程整備に活用する。
- 社員向けにはわかりやすく、管理者向けには根拠確認ができる表示にする。

## 5. 期待する成果

- 社内規程を対象としたAI質問回答システムのプロトタイプ。
- 社員の質問に対し、対象規程の中から関連条文を検索する仕組み。
- 回答と根拠条文をセットで表示する画面または試作ツール。
- 該当条文がない場合に、推測せず未整備事項として回答する仕組み。
- 未整備と判定された質問を蓄積し、今後の規程整備に活用するための一覧。

## 6. 想定する仕組み

| # | 内容 |
|---|------|
| 1 | 会社規程をPDFまたはテキストで登録する。 |
| 2 | 規程を条文単位または見出し単位に分割する。 |
| 3 | 社員の質問に近い条文を検索する。 |
| 4 | 見つかった条文だけを根拠にAIが回答する。 |
| 5 | 根拠条文が見つからない場合は、回答せず未整備として表示する。 |
| 6 | 未整備と判定された質問を記録し、規程改定の検討材料にする。 |

## 7. まとめ

本件は、社内規程をAIで便利にするだけでなく、AIが根拠のない回答をしない仕組みを作り、社員の確認業務の効率化と規程整備の見える化を同時に実現するミニDXである。
