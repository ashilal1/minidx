## 2. 会議目的

本キックオフ会議は、支援企業の業務課題を把握・整理し、デジタル技術を活用した実現可能な解決課題を検討するための基礎情報を収集することを目的とする。

## 3. ヒアリング項目（要件定義用）

### ① 業務の現状・課題

- **問い合わせ内容の特定（有給、慶弔休暇、出張旅費等）**
  - 約15種類の規程類一覧を後日送付いただく予定。
- **総務の対応工数（頻度・時間）の把握**
  - 現状、総務ご担当者様ほぼ1名で対応されているとのこと。
- **規程の保管形式（Word, PDF, 紙, 共有フォルダ）**
  - すべての規程類はPDF形式で電子化済み。一部提出用のフォーマット変換が必要な場合も、システム要求に応じた形式で準備可能。
  - 日常的な業務ファイルはWord形式およびExcel形式が主流。
  - RAG構築にあたり、PDF形式の規程類を取り扱うためのOCR処理導入の必要性について検討が必要。
    - → テキスト抽出精度の観点から、Markdown形式への変換を推奨。
- **改定・周知フローの確認**
  - サイボウズ上の通知機能にて規程改定を周知し、全社員が閲覧・確認する運用フローとなっている。

### ② 目指すゴールとAIへの期待値

- **利用シナリオ（Teams bot, Web画面, Excel等）の想定**
  - チャットボット形式でのシステム構築を要望。
  - サイボウズ基盤上での運用統合を理想的な構成として想定。
  - 利用中のサイボウズはクラウド版であることを確認。
- **根拠明示（第○条へのリンク等）の要否**
  - 回答根拠の明記（参照条文等の提示）は必須機能として要求。
- **規程外回答の挙動確認（「不明」と返すルール）**
  - 根拠条文が存在しない場合や未整備の可能性がある事項については、その旨を明確に通知する制御が必要。
  - 未解答処理の仕様：独自判断での補足を行わず、社内規程に明記されている事実のみを提示し、記載のない事項については「該当規定なし」と回答する仕組みとする。
- **見える化（質問履歴分析、網羅性チェック等）の優先度**
  - 「可視化」の要件として、システム導入を通じて社内規程の網羅性や整備状況の不備を把握し、分かりやすい規定体系の構築に繋げたいとの意図を確認。

### ③ システム・環境・セキュリティ

- **社内PC環境（OS）およびM365契約プラン**
  - 活用中の業務管理ツールはkintoneのみであることを確認。
  - kintoneは営業業務にて顧客関連資料の時系列管理に活用。
  - 外部とのデータ授受には大容量ファイル転送サービス（GigaFile便、データ便等）を利用。
  - Microsoft 365の契約・利用はなし。
  - 社内PCの標準OSはWindows 11に統一。
  - 自社用ファイルサーバーを2台所有しているが、管理・運用は外部業者へ委託中（開発システムのサーバー格納については委託先との個別調整により調整可能な見込み）。
- **AI利用に関する社内ポリシー（外部連携の可否）**
  - パブリックな汎用生成AIサービス（外部データ連携を伴うもの）の直接利用は回避したい意向。
  - 主要な社内規程に限定したプロトタイプをローカル環境上で構築し、検証を進める方針を設定。
- **ストレージ・USB利用制限の確認**
  - 外部とのデータ受け渡しにはポータブルSSDを使用している実態を確認。
  - 構築システムはポータブルSSD等を介して御社環境へ提供・運用いただく構成について検討を実施。
