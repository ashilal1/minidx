description: 今日の作業ログに追記する
argument-hint: [記録したい内容（省略可）]
allowed-tools: Bash(date *), Read, Edit, Write
---

`docs/log/$(date +%Y-%m-%d).md` に作業記録を追記する。

手順:

1. `docs/log/README.md` の書式を確認する。
2. 当日ファイルが無ければ `# 作業ログ YYYY-MM-DD` の見出しで新規作成する。
3. **末尾に追記する。既存のエントリは書き換えない。**
4. 見出しは `## HH:MM 見出し`（時刻は `date +%H:%M` の実測値を使う。推測で書かない）。

記録内容: $ARGUMENTS

引数が空の場合は、直近の会話で実際に行った作業から「やったこと / 決めたこと / 残課題」を組み立てる。
やっていないことを書かない。評価数値は実行済みの実測値のみを載せ、未実行なら「未実行」と書く。
