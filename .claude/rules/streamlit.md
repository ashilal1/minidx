# Streamlit 画面と認証

`docs/MVP要件定義.md` §3.6 / §3.7 / §7.3 が正本。

## 認証（Cloudflare Tunnel 公開の前提）

- 未認証時は `st.stop()` で **UI もデータも一切描画しない**。タブ名・サイドバー・
  アプリ名の推測材料も出さない。
- パスワードは `.streamlit/secrets.toml` に**ハッシュ値**で保持。平文をコードにも
  リポジトリにも置かない。`.gitignore` 必須。
- **社員用と管理者用でパスワードを分ける。** 管理者タブの質問ログには全社員の質問履歴が
  含まれるため、同一パスワードで見せてはならない。
- 認証失敗時は数秒スリープを挟む。
- `robots.txt` で `Disallow: /` を返す。

## 社員タブ

- 該当ありのとき: 回答文 ＋ 根拠条文カード（規程名／第○条／条見出し／条文原文）。原文は折りたたみで全文表示。
- 未整備のとき: **回答を一切出さず**、固定文言のみを表示する。
  **参考条文・近い条文の提示を行わない**（誤読を誘発するため）。

## 管理者タブ

- 未整備質問一覧（質問文・発生回数・直近日時、回数降順）、回答済み質問一覧、取込状況、CSV エクスポート。
