# Python 規約

- Python 3.12。依存追加は `uv add`（`pip install` を直接叩かない）。
- 公開関数には型注釈を付ける。`dict[str, Any]` を返り値にせず、`dataclass` で構造を明示する
  （特に検索結果・引用・判定結果。後続の照合処理がキー名の揺れで壊れるため）。
- 例外を握り潰さない。取込失敗は握り潰さず、規程単位でエラーとして集計し一覧報告する（`docs/MVP要件定義.md` §3.2）。
- コメント・docstring・ログメッセージは日本語。
- 「なぜこの実装か」が要件由来の場合は、該当節番号をコメントに残す（例: `# 要件 §3.4 ゲート2`）。
- マジックナンバー禁止。閾値・k・文字数上限・モデル名は `config.yaml` から読む。
- 時刻は `datetime.now(UTC)` ではなくローカル時刻で記録してよいが、DB 内で統一する。
